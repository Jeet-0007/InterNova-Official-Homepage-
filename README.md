# 🚀 InternNova — Official Homepage Redesign

A modern, professional, and fully responsive redesign of the [InternNova](https://internnova.co.in/) official homepage, built as a real-world internship project.

![InternNova Redesign](assets/images/hero-bg.jpg)

## 📌 Project Overview

This project is a complete homepage redesign for **InternNova** — India's leading virtual internship and skill development platform. The redesign focuses on modern UI/UX principles, premium aesthetics, smooth animations, and full responsiveness across all devices.

**Designed by:** Jeet Dey  
**Duration:** 1 Week  
**Type:** Mandatory Web Development Internship Task

## ✨ Features

- 🎨 **Modern Dark Theme** — Premium glassmorphism design with gradient accents
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices
- 🎬 **Smooth Animations** — Scroll-reveal effects, counter animations, parallax, and micro-interactions
- 🧭 **Smooth Navigation** — Sticky navbar with scroll effects and mobile hamburger menu
- 📊 **Interactive Elements** — FAQ accordion, animated counters, card tilt effects, and floating particles
- ⚡ **Performance Optimized** — Lightweight vanilla JS with no heavy frameworks
- 🔍 **SEO Friendly** — Semantic HTML5, proper meta tags, and heading hierarchy

## 🎯 Design Decisions

- **Dark theme** chosen to create a premium, tech-forward appearance
- **Glassmorphism** used for cards and nav to add depth and modernity
- **Gradient accents** (indigo → cyan) maintain brand identity while feeling fresh
- **Space Grotesk** font for headings adds a distinctive, modern character
- **Intersection Observer** for scroll animations (better performance than scroll events)
- **CSS custom properties** for consistent theming and easy customization
